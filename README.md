**AllReaderBook** — автономний, надшвидкий читач електронних книг та документів для Windows, оптимізований для високої продуктивності та низького споживання оперативної пам'яті навіть на слабких ПК.

---

### 🚀 Основні можливості

* **Підтримка поширених форматів:**
  * Документи: `PDF` (цифрові та скановані з векторним рендерингом), `DOCX`, `RTF`, `TXT`, `MD` (Markdown).
  * Електронні книги: `EPUB`, `FB2`, `MOBI` (`.mobi`, `.azw`, `.azw3`).
  * Графіка та архіви: `CBZ` (комікси), `DJVU`.
* **Висока швидкість рендерингу:** використання оптимізованого ядра PDFium та компіляції ReadyToRun для миттєвого відкриття важких файлів.
* **Багатомовний інтерфейс:** підтримка перемикання локалізації «на льоту» (Українська, English, Polski та інші).
* **Кастомізація читання:** темна, світла та сепія-теми, гнучке налаштування шрифтів, міжрядкового інтервалу, розворотів сторінок та масштабування.
* **100% Приватність:** нуль телеметрії, жодних мережевих опитувань чи прихованої аналітики. Повна працездатність без доступу до інтернету.
* **Портативність:** налаштування зберігаються у файлі `allreaderbook_settings.json` поруч із програмою, не засмічуючи системний реєстр.

### 📥 Завантаження (Releases)

Готові збірки для Windows x64 доступні у розділі **[Releases](../../releases)**:

* **Installer (`.exe`)** — майстер встановлення з інтеграцією в систему та контекстне меню файлів.
* **Portable (`.zip`)** — портативна версія, готова до роботи з USB-накопичувача чи будь-якої папки без інсталяції.
