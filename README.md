**AllReaderBook v0.9.02-beta** — надшвидкий, легкий і 100% офлайн-рідер для Windows (`win-x64`). Побудований на базі .NET 9 WPF та нативного рушія Google PDFium із нульовою телеметрією. Забезпечує миттєвий старт, розумний нічний режим для PDF, багатовкладковий режим із закріпленням документів та експорт нотаток для Obsidian.

---

## 📦 Варіанти дистрибутивів

1. **Автономний інсталятор:** `AllReaderBook_Setup_v0.9.02-beta_x64.exe` (Inno Setup, підтримка тихих ключів `/VERYSILENT /NORESTART`, асоціація типів файлів у системі).
2. **Портативна збірка:** `AllReaderBook_Portable_v0.9.02-beta_win-x64.zip` (повністю автономний запуск без встановлення в систему та без запису до реєстру).

### Встановлення через Windows Package Manager (Winget):
```powershell
winget install RomanMyrovych.AllReaderBook
```

## ✨ Ключові можливості v0.9.02-beta

- **🌓 Розумний Нічний та Сепія режим для PDF (*Smart Dark & Sepia Mode*):**
  - Адаптивна хрома-чутлива перекольоровка (`< 0.8 мс` на сторінку через оптимізовану LUT-таблицю) перефарбовує сліпучо-білий фон сторінки та темний текст під обрану тему.
  - Зберігає природні насичені кольори на діаграмах, фотографіях та кольорових ілюстраціях.
  - Вмикається кнопкою **`🌓 PDF-тема`** на панелі або в налаштуваннях (`F2`).
- **📌 Відновлення сесії та закріплені вкладки (*Pinned Tabs*):**
  - Повне збереження списку відкритих і закріплених вкладок між сеансами з відновленням номера сторінки, піксельного зсуву скролу та масштабу.
  - Лінива ініціалізація фонових вкладок (0 МБ RAM на старті до моменту переходу на вкладку).
  - Можливість закріплювати важливі книги (`📌 Закріпити вкладку`) із захистом від випадкового закриття.
- **⚡ Архітектура екстремальної швидкості:**
  - **ReadyToRun (R2R) AOT:** Відкриття важких PDF-книг на 600–1500+ сторінок за десятки мілісекунд.
  - **Фіксований пул пам'яті (`PdfSurfacePool`):** Контрольоване використання RAM і відеопам'яті навіть при десятках одночасно відкритих вкладок.
- **🔍 Інструменти дослідника та Obsidian:**
  - Посимвольне виділення тексту, підсвічування збігів під час швидкого пошуку `Ctrl+F`.
  - Створення нотаток, маркерів та експорт конспектів у формат Markdown (`.md`) для бази знань **Obsidian**.
- **🎨 5 тем оформлення та 10 мов інтерфейсу:**
  - Теми: *Obsidian Dark*, *Nord Dark*, *OLED Black*, *Warm Sepia*, *Nord Light*.
  - Контрастне акцентне підсвічування активного пункту змісту (TOC) та активної вкладки.
  - Повна локалізація інтерфейсу на 10 мов (*UK, EN, PL, DE, ES, FR, IT, PT, JA, ZH*).
- **📖 Режими перегляду:**
  - `Безперервний вертикальний скрол`, `1 Сторінка`, `Розворот (2 сторінки)` та `◫ Split-View` (паралельний перегляд двох документів поруч).

## 💻 Системні вимоги

- **Операційна система:** Windows 10 / Windows 11 (64-bit)
- **Архітектура:** `win-x64`
- **Оперативна пам'ять:** від 1 ГБ RAM
- **Середовище виконання:** .NET 9.0 Desktop Runtime (для компактного портативного варіанту) або автономно (в інсталяторі)

## 🛠 Збірка з вихідного коду

```powershell
# 1. Компіляція AllReaderBook у режимі Release (ReadyToRun)
dotnet build .\AllReaderBook.csproj -c Release

# 2. Створення автономного портативного пакету (ZIP)
powershell -ExecutionPolicy Bypass -File .\Publish-Reader-Portable.ps1

# 3. Створення автономного інсталятора (потребує Inno Setup 6)
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" .\installer_allreaderbook.iss
```

## 🔒 Конфіденційність та безпека

**AllReaderBook** працює за принципом **100% Offline-First**:
- Жодних мережевих запитів, реєстрацій чи хмарних сервісів.
- Повна відсутність телеметрії, рекламних модулів або прихованих трекерів.
- Усі закладки та налаштування зберігаються локально у файлі `allreaderbook_settings.json`.
- Докладніше див. у файлі [PRIVACY.md](PRIVACY.md).
